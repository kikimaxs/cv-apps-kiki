# CV Viewer & Portfolio Generator

A professional Flutter application designed to be your digital CV, portfolio, and resume generator. It features a responsive, modern interface with both light and dark mode support, skill analytics, and multi-language capabilities.

## Features

- **Multi-Page Layout**: Alternates between Light and Dark modes for a dynamic reading experience.
- **Skill Analytics**: Visualize your technical skills with dynamic bars and proficiency levels.
- **Interactive Components**:
  - **PDF Viewer**: Integrated PDF reader to display your resume.
  - **Web Viewer**: Embed external web content or interactive prototypes.
  - **Video Player**: Showcase video testimonials or project demonstrations.
  - **Image Zoom**: Pinch-to-zoom functionality for images and profile pictures.
- **Export Functionality**:
  - Generate **Printable PDFs** directly from your CV.
  - **Quality Settings**: Export in Standard, High, or Ultra quality.
  - **QR Code**: Automatically generated and embedded in the footer for easy access.
- **Animation**: Smooth scrolling physics and page transitions.
- **Responsiveness**: Optimized for both desktop and mobile devices.

## Getting Started

### Prerequisites

- Flutter SDK (stable channel recommended)
- Java (for Android development)

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd cv_apps
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

### Running the App

Start the development server:

```bash
flutter run
```

## Usage

- Navigate through your CV using the scroll wheel or touch gestures.
- Click on the "Export CV" button in the top-right corner to save a PDF version.
- Use the "Toggle Light/Dark Mode" button in the top-right corner to switch the theme.
